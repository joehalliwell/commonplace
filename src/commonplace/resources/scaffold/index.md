# Primitives

- [Chats](chats/) - imported AI conversations, by agent and date; written by
  `commonplace import`/`fetch`
- [Memory](memory/) - agent memory, mirrored from each agent by
  `commonplace fetch`
- [Journal](journal/) - daily entries, written by `commonplace journal`
- [Notes](notes/) - general notes, ideas, todos, projects etc.

# Derived

- [Topics](topics/) - syntheses of recurring themes, written by `/synthesize`
  and `/resonate`; never a source
