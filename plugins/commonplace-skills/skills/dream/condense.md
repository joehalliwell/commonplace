# Scenes

The calling agent's prompt gives a value for each `{placeholder}`.

You get a list of images, shuffled, from unrelated sources you will never
see. Arrange them into scenes. Don't search, read files or guess where they
came from: work only with these.

**Images**

{images}

## Make Scenes

Build three to five scenes from the list, using most of it.

- **Merge images**: one person, object or place standing for two. At least
  one merge across the scenes; more where they come naturally.
- **Emphasis needn't follow importance.** What would be striking can be
  passed over; something small can matter.
- **Places and people, not plot.** Each scene says where it is, who or what is
  there, and what is happening.

## Return Value

Return **only** the scenes, each a short paragraph headed `Scene <n>:`.
